# LumaTodo 1.2

LumaTodo 是适用于 macOS 26 及以上版本的原生桌面待办工具。任务、提醒配置和文件附件保存在本机。界面默认使用简体中文，可在设置中切换英文。

## 下载与安装

在 [GitHub Releases](https://github.com/youai6656-prog/LumaTodo/releases/latest) 下载 `LumaTodo-1.2.0-macOS-arm64.zip`。需要 Apple Silicon Mac 和 macOS 26 或更新版本。解压后，将 `LumaTodo.app` 拖到「应用程序」并打开。更新前请先退出旧版。

目前发布包采用本地签名，未获 Apple 公证。如果 macOS 阻止首次启动，请核对下载来源和 Release 附带的 SHA-256，再通过「系统设置 → 隐私与安全性 → 仍要打开」允许这一次应用。如需核对，可在 ZIP 所在目录运行 `shasum -a 256 LumaTodo-1.2.0-macOS-arm64.zip`。

## 从源码构建

本地构建后的应用位于 `Release/LumaTodo.app`，应用标识为 `io.lumatodo.mac`。

可在 Xcode 26 或更新版本打开 `LumaTodo.xcodeproj`，选择 **My Mac** 后运行。使用 Command Line Tools 时需要 Swift 6.2 及 macOS 26 SDK。

```sh
./Scripts/build-app.sh
open Release/LumaTodo.app
./Scripts/test.sh
./Scripts/test-persistence.sh
./Scripts/test-native.sh
```

构建脚本默认使用 ad-hoc 签名。用于向其他 Mac 分发的构建可通过 `LUMATODO_SIGNING_IDENTITY` 指定开发者签名身份，并走 Apple 的公证流程。

## 编辑任务

在浮窗底部输入标题并按回车可快速添加。点右上角的 **+** 或按 `⌘N` 打开详细表单，点击已有任务标题可编辑。输入标题后按 `⌘↩` 或点击「保存任务」。`Esc` 返回列表，有未保存的更改时会先确认。表单内容较多时在面板内滚动，保存和取消按钮固定在底部。

截止日期可使用今天、明天快捷项，再按需设置具体时间。高级设置包含优先级、标签、重复和两类提醒。截止提醒按截止时刻或自定义提前量触发，独立提醒可直接指定日期和时间，即使任务无截止日期也能使用。独立提醒为单次提醒。

## 文件附件

- 在任务描述右侧点回形针，可从系统文件选择器一次添加多个文件。也可以从 Finder 拖入描述区域，或将复制的 Finder 文件和剪贴板图片粘贴到描述框。普通文本照常粘贴到描述中。
- 单个文件上限为 50 MB。导入完成后，文件名、大小和图标会显示在描述下方，图片使用小尺寸缩略图。保存任务后，主列表显示回形针和数量。
- 点击文件进入 Quick Look。附件菜单可按系统关联应用打开，或在 Finder 中显示应用管理的副本。具体预览支持取决于 macOS 和文件类型。无法预览时，可尝试使用关联应用。LumaTodo 的打开操作会拦截可执行文件及识别出的脚本启动器。
- 点击附件右侧的移除按钮，再保存任务。取消编辑会清理本次新导入的文件，仅在保存后确认对既有附件的移除。删除任务会移除它的附件关联。重复任务的历史记录和系列可共同引用同一份副本，最后一个关联移除时清理文件。

## 1.1 数据兼容与附件存储

数据目录为 `~/Library/Application Support/io.lumatodo.mac/`，数据库仍为 `Tasks.store`。1.2 保留 1.1 的任务实体和字段。SwiftData 通过轻量迁移新增独立的 `Attachment` 实体，用任务 UUID 建立一对多关联。旧的稍后提醒数据可按原格式读取。加入独立提醒后，扩展信息与稍后提醒共用已有字段。已有任务、完成历史、重复和提醒配置无需手工导入。

文件内容保存在数据库旁的 `Attachments/Files/`，只在 SwiftData 存元数据与相对路径。复制先在同一卷的 `Attachments/Staging/` 后台完成，保存时移动文件并提交任务与附件元数据。提交失败会尝试回退暂存，以便重试；启动时清理上次中断留下的无关联副本。原始文件的移动、改名或删除不会影响已保存的副本。

完整备份时先退出应用，再复制整个数据目录，包括数据库和 `Attachments`。

## 浮窗与提醒

- 主窗口保持自动尺寸、置顶、边缘收起和迷你模式。拖动窗口标题移动，拖边缘改尺寸。「设置 → 窗口」可恢复自动尺寸。默认全局快捷键 `⌥⌘T` 显示或隐藏窗口。
- `⌘F` 搜索任务，`⌘Z` 可恢复最近完成。输入框有可撤销文本时，`⌘Z` 优先用于文字。
- 「设置 → 提醒」显示权限、系统队列与测试通知。改期、完成或删除后会重新对账，最多滚动保留 60 条任务提醒。完全退出后，系统可投递已经排队的提醒，尚未排队的提醒会在应用再次运行后补充。
- 系统横幅、声音和专注模式由 macOS 管理。多桌面、全屏及登录启动由系统设置决定。

## 工程结构与验收

- `Models` 保存 TaskItem、附件元数据和提醒配置。 `Services` 负责 SwiftData 事务、本地文件、预览和通知队列。
- `Views` 保存玻璃浮窗、可读性更稳定的编辑表单和原生文本输入。 `WindowManagement` 负责尺寸、磁吸和 Spaces。
- `Tests` 包含 Swift Testing 用例、从 1.1 生成的合成数据库样本、跨进程持久化和原生窗口探针。

详见 [验收记录](TESTING.md)。后续可以加入附件导出和更丰富的文件管理，同时验证在大量附件或第三方文件提供器下的性能。
